## State the limits accurately

The demonstration can use labeled staged clothing and location. Visa payment is simulated without a real API or funds transfer. Current Photon shared lines support private conversations; live group chat is not verified. The demo identity selector is not production authentication. User feedback is pending until actual responses are received.

ASI:One qualification is not a project goal. Do not submit claims of an ASI:One conversation or registration based on legacy agent experiments.

For Photon, demonstrate private iMessage recognition and action only after showing the actual phones. For Visa, describe a simulated authorization/capture flow and explicitly state that no Visa API or sandbox was provided. The Base44 challenge is the central product story.
