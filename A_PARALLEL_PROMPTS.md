# Part A — World & Art, split into 5 parallel agents

How to use: open **five** Fable sessions in the same repo. In each one paste, in this order:

1. **Part 0** (General) from `HACKATHON_PROMPTS.md`
2. **Part D** (Pixel design system)
3. **Part A** (for the overall vision — the agent is told below to ignore Part A's build order)
4. **The shared block "A-team internal contract"** (below, identical for all five)
5. **That agent's own prompt** (A1–A5)

Merge order on `main` (Freja integrates): **A1 → A2 → A3 → A4 → A5**. A1 is the only blocker: B and C are waiting on it at 10:30 PM, so A1 is the session to watch first.

| Agent | Branch | One line |
|---|---|---|
| A1 Kit | `world-kit` | tokens, fonts, 9 components, `sfx.ts` player, `/kit` page |
| A2 Art | `world-art` | every sprite, sound, GIF and the app icon, generated by scripts; `Sprite`, `ItemIcon`, `sprites.ts`, `/dev/art` |
| A3 Shell | `world-shell` | TitleScreen, audio/location unlock, handheld bezel, bottom bar, mute toggle, iOS/PWA meta |
| A4 World | `world-map` | `/world`: lawn, radar, GPS → `updatePresence`, `listNearby` placement, chips, demo walk |
| A5 Encounter | `world-encounter` | EncounterScene, Celebration, `particles.ts`, `/dev/encounter` loop |
